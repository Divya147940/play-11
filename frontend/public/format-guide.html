Quiz Ingestion Format Reference

Use this comprehensive template and format guide to ensure error-free bulk quiz upload configurations.

📁 CSV Format
CSV File

Best for tabular data exported from spreadsheet editors like Excel or Google Sheets.

Columns Layout (6 fields)
  • Column 1: Question Text (English)
  • Column 2: Option A
  • Column 3: Option B
  • Column 4: Option C
  • Column 5: Option D
  • Column 6: Correct Answer Index (Must be 0, 1, 2, or 3)
CSV Format Example 
"What is the capital of India?","Mumbai","New Delhi","Chennai","Kolkata",1
"Which HTML element defines critical text?","<b>","<i>","<strong>","<important>",2
📝 Plain Text Format (TXT)
Text / Copy-Paste

Great for quick copy-pasting from word documents, chat logs, or formatted notes.

Rules & Layout
  • Question: Place a ❓, Question, Q:, or number indicator (e.g. 1.) at the start.
  • Options: List option lines starting with A., B., etc. Emojis/shapes (e.g., ◈) before letters are allowed.
  • Correct Option: Place a checkmark emoji ✅ or ✔️ next to the correct answer to auto-select it.
Plain Text Example 
╔═══════════════════════════╗
║ 📘 QUESTION 1             ║
╚═══════════════════════════╝

❓ CSS ka use kis liye hota hai?

◈ A. Database banane ke liye
◈ B. Website design aur styling ke liye ✅
◈ C. Video editing ke liye
◈ D. Hacking ke liye
💻 JSON Format
JSON Array

Standard structured JSON schema, perfect for developers or automated exports.

Schema Fields
  • text: The string representing the question.
  • options: An array of exactly 4 items containing option texts (e.g. {"text": "Option Text"}).
  • correctOptionIndex: The integer (0-3) indicating the correct option.
JSON Array Example 
[
  {
    "text": "What is the result of 5 + 3?",
    "options": [
      { "text": "6" },
      { "text": "7" },
      { "text": "8" },
      { "text": "9" }
    ],
    "correctOptionIndex": 2
  }
]
📷 PNG / JPG Image format
OCR Ingestion

Scan and extract text directly from images or screenshots.

Image Guidelines
  • Ensure the image resolution is high and the text is readable.
  • The text in the screenshot should follow the standard Plain Text layout rules described above.
  • Avoid shadows, low contrast background, or handwritten text.
